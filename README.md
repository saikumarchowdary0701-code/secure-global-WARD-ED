# WARD-ED – Workforce Attendance Reporting and Exception Detection

## ICT802 Capstone Project – Group M37

WARD-ED is a prototype designed to improve workforce attendance monitoring and reporting by identifying attendance exceptions and providing structured reporting capabilities.

### Project Organisation
SecureLock Global – Oakleigh VIC Branch

### Project Features
- Attendance summary dashboard
- Employee onboarding
- Attendance data management
- CSV attendance import
- Exception detection
- Late arrival identification
- Missing clock-in and clock-out detection
- Overtime and roster violation identification
- Attendance reporting and export

### Technology Stack
- Frontend: React
- Backend: Node.js and Express (as implemented)
- Database: PostgreSQL/MySQL (as implemented)
- Hosting: Netlify

### Live Project
https://secure-global.netlify.app/

### Project Purpose
This prototype demonstrates how an attendance reporting system can help organisations identify attendance exceptions and improve workforce reporting processes.

**Note:** This is an academic prototype using sample data. It is not connected to SecureLock Global's live employee or attendance systems.
