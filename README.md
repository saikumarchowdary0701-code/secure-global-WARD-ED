# WARD-ED — SecureLock Global
### Workforce Attendance Reporting & Exception Detection

A fully working front-end prototype for the ICT802 final project.
No build tools, no dependencies — pure HTML/CSS/JS.

## Features
- **Role selection login** — HR, Payroll, Manager, Finance
- **HR dashboard** — company-wide stats, attendance rate, recent exceptions
- **Manager dashboard** — Operations-only view with today's exceptions
- **Payroll dashboard** — overtime hours, unverified records, missing punches
- **Finance dashboard** — labour cost, overtime cost, charts
- **Attendance page** — date picker, department filter, live search, status filter, CSV export
- **Exception Detection** — severity cards, review modal (Resolve / Escalate / Comment) with live state updates
- **Reports** — weekly attendance chart (pure SVG), CSV export, print-to-PDF
- Fully responsive (desktop, tablet, mobile)

## Run it
Open `index.html` in any browser — that's it.
